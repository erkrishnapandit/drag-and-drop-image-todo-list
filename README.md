# Drag & Drop Image Uploader

A sleek and modern drag-and-drop image uploader built using HTML, CSS, and JavaScript. Easily upload images by dragging them into the drop zone or using the file selector.

🔗 **Live Demo**: [https://kp-dragndrop-image-upload.netlify.app/](https://kp-dragndrop-image-upload.netlify.app/)

## 📌 Features

- 🖱️ **Drag & Drop Support**: Simply drag an image into the upload area to preview it.
- 📂 **Manual File Selection**: Alternatively, click to browse and upload images using the file input.
- 🖼️ **Live Preview**: Instantly see the selected image before uploading.
- ❌ **Remove Option**: Remove the previewed image with a single click.
- 💡 **User-Friendly UI**: Minimal, responsive, and clean design optimized for a smooth user experience.

## 🛠️ Tech Stack

- **HTML5** – Structural markup
- **CSS3** – Modern and responsive styling
- **JavaScript (ES6)** – Handles file reading, drag-and-drop events, and preview rendering
- **Netlify** – Deployment and hosting
